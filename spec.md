# Landing Page - Patrimônio e Sucessões

## O que é?
Uma página de vendas para um escritório de advocacia e assessoria empresarial.

## Tecnologias utilizadas
Desenvolvida com React, Vite, TypeScript, Tailwind CSS e Motion.

## Deploy
Docker (Nginx no container) + Traefik na VPS, subdomínio sucessoes.reboucasbulhoes.com.
